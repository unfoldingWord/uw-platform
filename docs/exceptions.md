| 2026-09-30 | Section 10: no agent identity can deploy past a human gate, by any route | `.github/workflows/`, repository secret `CLOUDFLARE_API_TOKEN` | The repository is private on GitHub's Free plan, so environment secrets restricted to `main` and tags are unavailable, and GitHub gives every repository secret to any workflow a writer pushes. Cloudflare's Workers Scripts permission cannot be limited to one Worker, and production `uw-app` shares the account with staging. So any writer, including an agent pushing with a DRI's credentials, could deploy production with a workflow written for the purpose. #80 closes every path that runs PR code with the token (builds without secrets, deploys from main's workflow definitions, a test refusing secrets in `pull_request` workflows); this residual path remains. It closes with GitHub Team or a public repository (environment secrets), or a separate Cloudflare account for production. | Ian (DRI), on #80 |
