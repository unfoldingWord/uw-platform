# Proposals

A proposal is a short markdown file here, `<date>-<slug>.md`, with four headings: Problem, Change, Alternatives, Rules affected. Write it, stop, and ask a human before touching a shared root (`AGENTS.md`, `CONTEXT.md`, `docs/adr/`, `packages/db/schema.ts`, `packages/contracts/`, `infra/`, `.github/workflows/`). If it is accepted and the decision is hard to reverse, surprising without context and the result of a real trade-off, it also becomes an ADR.
