Layout

Five page shapes. Every screen is one of them.

A new screen names its page shape in the pull request, the way AGENTS.md rule 1 already asks for code. Each shape is a component in packages/ui/shapes/, so a screen fills slots instead of arranging boxes.

The frame

Kept from ADR 0014, made quieter.

• Sidebar stays Ocean. Area codes move from every row to group labels; unbuilt modules are hidden behind "More" instead of shown dimmed.

• Top bar holds breadcrumb and search only. Page actions live in the page head, not the bar.

• Content is white, not canvas grey, with a max width of 1080 and a 32 gutter (24 on phone).

• Status bar folds into a single dot in the top bar that opens the same facts.

List

ListShape

Page head, filter chips, ListRow or Table. Row opens a side panel. For: Waiting On You, Runs, Collections, Credentials, Search, Agents, Health list.

Document

DocumentShape

Reading column of 48rem, properties in a quiet right rail that collapses under the title on phone. For: wiki and pages, a run, play-by-play, persona, a record.

Form

FormShape

One centred column, one field per row, the primary action bottom right, outcome shown under it. For: new workflow, new agent, new page, access, settings, export.

Board

BoardShape

Full-width lanes of ObjectCards, the one place cards stack on a grey ground. Lanes scroll sideways on phone. For: queue, Agent Queues, epic board, flow.

Overview

OverviewShape

A row of up to four figures, then a main list and a narrow side list. Figures are the only cards. For: Today, Health.

Doesn't fit?

Pick the nearest shape, say which and why in the pull request, and add the gap to this canvas. A sixth shape is a design change, the same as a new token.

Rule: a screen file may import from packages/ui/shapes and packages/ui/components; it may not set grid, max-width or page padding itself.
