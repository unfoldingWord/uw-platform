Why two axes

the section an adopting organization reads first

Johnny.Decimal · functional

Where a thing lives. Stable, addressable, mirrored in shared drives and chat folders. Changes rarely — a renumber is an org restructure. Answers “where do I file this.”

Strategic Cascade · strategic

Why a thing exists. Purpose → portfolio → program → project → task. Supposed to change every planning cycle. Answers “what outcome does this serve.”

The failure this prevents

Model only one axis and the other gets smuggled in as duplicated select fields — exactly the portfolio-select duplication and the parallel grant taxonomy the migration is paying off.
